UPLOAD-STAPPEN
------------------------------------------------------------

1. Pak deze ZIP uit in een lege werkmap.

2. Kopieer de INHOUD van die werkmap (dus niet de map zelf,
   maar alle bestanden erin) naar de root van je GitHub repo.

3. Als je git op de command-line gebruikt:

     cd ~/dierenkliniek-nl-repo
     rm -rf *.html *.xml *.txt *.svg *.png *.ico *.zip
     rm -rf badges/ logo-pack/
     # Kopieer alles uit de uitgepakte werkmap hierheen
     cp -r ~/Downloads/dierenkliniek-upload/* .
     git add -A
     git commit -m "Complete deployment: alles bijgewerkt"
     git push

4. Wacht 2-5 minuten tot GitHub Pages jouw wijzigingen deployeert.

5. Controleer op https://dierenkliniek.nl of alles werkt.
