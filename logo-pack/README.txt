------------------------------------------------------------
WELK BESTAND WANNEER GEBRUIKEN?
------------------------------------------------------------

WEB & DIGITAAL:
  → Gebruik altijd SVG als het kan (schaalbaar, klein bestand)
  → Anders PNG @ 2x de weergavegrootte voor scherpe retina-weergave
  → App icoon / favicon: dierenkliniek-nl-icon-1024.png

DRUKWERK:
  → Gebruik altijd de PDF of SVG (vector = geen pixels)
  → Bij PNG: minimaal 300 DPI (dus voor 10cm breed: 1200px+)
  → Voor visitekaartjes: dierenkliniek-nl-horizontaal.pdf
  → Voor banners: dierenkliniek-nl-horizontaal.svg schaal je

SOCIAL MEDIA:
  → LinkedIn / Facebook profielfoto: dierenkliniek-nl-gestapeld-1024.png
  → Cover-afbeelding: dierenkliniek-nl-horizontaal-1024.png
  → Instagram post: dierenkliniek-nl-icon-1024.png of horizontaal

DONKERE ACHTERGROND / VIDEO:
  → Gebruik de "-wit" varianten
  → Bij foto's: gebruik de icoon alleen op een licht vlak

KLEUREN
------------------------------------------------------------

Primair blauw:   #00A1E4  (rgb 0, 161, 228)
Deep blauw:      #0070AC  (rgb 0, 112, 172)
Diep blauw:      #003E7E  (rgb 0, 62, 126) — gradient-eind
Tekst-donker:    #0a1628  (rgb 10, 22, 40)
Wit:             #FFFFFF

Gradient logo-tegel: 135° van #00A1E4 → #003E7E

------------------------------------------------------------
DO'S & DON'TS
------------------------------------------------------------

WEL:
  ✓ Behoud altijd de kleuren zoals hierboven aangegeven
  ✓ Zorg voor voldoende witruimte om het logo (minimaal 1/4 van
    de hoogte van het icoon)
  ✓ Gebruik SVG of PDF waar mogelijk voor scherpe weergave
  ✓ Gebruik het icoon-only als apart element (bijv. als "bullet"
    of ter afsluiting)

NIET:
  ✗ Vervorm het logo niet (behoud proporties bij schalen)
  ✗ Verander de kleuren niet
  ✗ Draai het logo niet
  ✗ Voeg geen effecten toe (schaduwen, glow, outlines)
  ✗ Plaats geen tekst binnen het icoon-vierkant
